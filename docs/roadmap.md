# 开发路线图

## 第一阶段：可靠基础（已完成）

- [x] Git、pnpm、Next.js App Router、TypeScript、Tailwind CSS、shadcn/ui
- [x] ESLint、Prettier、路径别名、环境示例
- [x] SQLite / Drizzle 五张业务表、初始 Migration
- [x] 首页、详情、投稿、登录、后台概览、审核、照片管理骨架
- [x] 主题切换、空状态、公开查询隐私边界
- [x] R2、Sharp、Better Auth、Turnstile、投稿、审核接口
- [x] 中文文档、Docker 持久化配置、基础集成测试

## 第二阶段：认证与投稿审核闭环

1. 生成 Better Auth Schema / Migration，安全初始化管理员，关闭公众注册，接入角色检查、会话、退出和后台保护。
2. 接入 R2 私有桶和文件校验：大小、MIME、文件签名、像素上限、批次限额。
3. 实现 Turnstile 服务端验证、超时/重放检查与单实例限流；决定持久化策略，避免只靠内存计数宣称可靠限流。
4. 匿名投稿保存私有原图和 `pending` 记录，处理失败补偿，显示真实结果。
5. 私有预览、批准/拒绝、备注、Sharp 去 EXIF 优化、发布与事务审核日志。
6. 展示图/缩略图访问、隐藏与恢复、撤销公开资源、缓存失效。

验收：匿名投稿不提前公开；管理员登录后完成审核；公众只能访问获批展示图；原图和联系方式不泄露；失败/重试不造成假成功或失控孤立文件。
